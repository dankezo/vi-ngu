# Ví Ngủ — Sleep Wallet

Ví ngủ: theo dõi nợ ngủ 14 đêm, điểm ngủ 0–100 và kế hoạch trả nợ 7 đêm.
Dữ liệu chỉ lưu trên trình duyệt, không cần đăng nhập.

Live: https://dankezo.github.io/vi-ngu/

- Ghi giờ đi ngủ / dậy, độ trễ vào giấc, thói quen mỗi đêm
- Số dư nợ ngủ 14 đêm, hạng ví Silver → Black
- Biểu đồ 14 đêm + đường nợ cộng dồn, kế hoạch trả nợ 7 đêm
- Máy tính giờ ngủ theo chu kỳ 90 phút
- Sổ cái + xuất / nạp file JSON
- Nhạc ngủ WebAudio (8 track) + hẹn giờ tắt
- Slime ngủ 3D (Rimuru GLB, CC-BY tommdraws): đổi màu, trạng thái và biểu cảm theo nợ ngủ, chọc để núng nính

Built with Lovable, then pulled back and hand-edited locally (TanStack Start + React Three Fiber).
